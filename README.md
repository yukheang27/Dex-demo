# MeetNotes AI - Landing Page

A modern, professional landing page for an AI-powered meeting notes and summarization platform.

## 📁 Files

- **landing.html** - Main professional landing page showcasing the AI meeting notes service
- **test.html** - Demo/test page (existing)
- **index.html** - Original demo (existing)

## 🎨 Features

### Landing Page (landing.html)

The new professional landing page includes:

1. **Navigation Bar** - Sticky header with logo and navigation links
2. **Hero Section** - Compelling headline with CTA buttons
3. **Features Section** - 6 key features with icons:
   - Real-time Transcription
   - Automatic Summarization
   - Smart Search
   - Speaker Identification
   - Action Item Tracking
   - Integrations

4. **How It Works** - 3-step process visualization
5. **Benefits Section** - Key advantages for teams
6. **Pricing Section** - 3 pricing tiers (Starter, Professional, Enterprise)
7. **Testimonials** - Customer success stories
8. **FAQ Section** - Interactive accordion with common questions
9. **CTA Section** - Final call-to-action
10. **Footer** - Links and company info

## 🎯 Design Highlights

- **Modern Gradient Design** - Beautiful blue and cyan gradients
- **Responsive Layout** - Mobile-friendly on all devices
- **Smooth Animations** - Fade-in animations for visual interest
- **Interactive Elements** - Hover effects and FAQ accordion
- **Professional Color Scheme** - Blue (#1e40af), Cyan (#06b6d4), and neutral grays
- **Clean Typography** - System fonts for fast loading

## 🚀 How to Use

1. Open `landing.html` in a web browser to see the complete landing page
2. All sections are interactive with smooth scrolling navigation
3. The FAQ accordion can be clicked to expand/collapse
4. Buttons are styled but currently non-functional (you can add handlers)

## 💻 Technology

- Pure HTML5
- CSS3 with modern features (Grid, Flexbox, Gradients)
- Vanilla JavaScript for interactivity
- No external dependencies or frameworks

## 🎨 Customization

You can easily customize:

- Colors by editing the CSS `:root` variables
- Content text in the HTML
- Button actions by adding event listeners
- Images by replacing emoji placeholders with actual images
- Pricing tiers and features

Works on all modern browsers:

- Firefox 88+
